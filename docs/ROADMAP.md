## 验收方式

- `./verify.sh`：单测、静态检查、前后端构建；存在 Docker 时追加数据库集成和镜像构建。
- `./smoke-test.sh`：部署后验证存活、就绪、元数据和受保护指标。
- CI：在 PostgreSQL 16 上执行全部数据库集成测试，构建两个镜像，启动生产 Compose 栈并执行 HTTP 冒烟。
