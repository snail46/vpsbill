# Telegram 绑定与奖励

客户把站点账号和 Telegram 账号绑定后，在站点的 Telegram 交流群里签到、邀请新成员可以获得账户余额。余额只能在本站消费（购买、续费），不能提现。

## 开启步骤

1. 在 Telegram 找 `@BotFather` 发送 `/newbot` 创建机器人，记下 Token。
2. 后台「站点设置 → Telegram 绑定与奖励」填入 Token 并保存（先不勾选启用）。
3. 把机器人拉进交流群，设为**管理员**，至少给「邀请用户」和「删除消息」两项权限。
   - 只有管理员才能收到群里的普通消息（「签到」两个字不是命令）和成员进群、退群的消息。
   - 「邀请用户」用于给每个客户生成专属邀请链接；「删除消息」用于自动清理机器人在群里的回复。
4. 回到设置页：公开群填 `@群用户名`；私有群在「机器人所在的群」里点选（保存 Token 后再拉机器人进群，才会出现在列表里），也可以直接填群 ID（`-100…`）。
5. 点「测试连接」，没有警告后勾选「启用」并保存。

服务器访问不了 `api.telegram.org` 时，在「Bot API 地址」填一个反向代理地址。

机器人用长轮询接收消息，不需要公网回调地址。多个 API 实例同时运行时只有一个实例轮询（数据库锁），其余待命。Token 加密保存；用 `rotate-key.sh` 轮换主密钥时会一并重新加密。

## 客户怎么用

- **绑定**：启用后，没绑定的客户在前台右下角会看到「绑定 Telegram，签到领余额」的小卡片，「账户资料」页也有完整的 Telegram 面板。点「绑定」会打开机器人对话，在 Telegram 里点「开始 / Start」即完成，页面自动更新。绑定链接 10 分钟内有效，只能用一次。
- **签到**：在群里发送「签到」「打卡」或 `/checkin`，每天一次（按 UTC+8 的自然日），金额在设置的最小值和最大值之间随机。
- **邀请**：发送 `/invite`（或在「账户资料」页生成），机器人私聊发来专属邀请链接。新成员通过这个链接进群并满足条件后，邀请人获得奖励，机器人会私聊通知。
- **查询**：`/me` 查看余额、签到天数和邀请情况；`/help` 查看说明。

机器人在群里的回复默认 60 秒后自动删除，避免刷屏；涉及个人信息的内容（邀请链接、余额）只私聊发送。回复的语言跟随客户在站点选择的语言。

## 奖励规则与防刷

都在设置页调整。金额按站点的默认币种填写和展示（默认币种在「站点设置 → 语言与币种」里设置，下表以人民币为例）；默认币种是美元时，奖励在发放时按当时汇率换算成人民币存入余额：

| 项目 | 默认 | 说明 |
| --- | --- | --- |
| 绑定奖励 | ¥1 | 每个站点账号、每个 Telegram 账号各只发一次，解绑重绑不再发 |
| 每日签到 | ¥0.10–¥0.50 | 每个站点账号和每个 Telegram 账号每天各限一次 |
| 邀请奖励 | ¥1 / 人 | 见下 |
| 被邀请人留群时间 | 24 小时 | 期间退群的不计奖励 |
| 被邀请人需绑定站点账号 | 开启 | 被邀请人注册并绑定站点账号（邮箱已验证）后才计奖励 |
| 每人每日邀请奖励上限 | 10 人 | 超出的顺延到次日结算 |
| 全站每日奖励总预算 | ¥100 | 当天发完后签到提示「奖励已发完」，邀请奖励顺延到次日 |

防刷措施：

- 只有**邮箱已验证**的站点账号能绑定，一个 Telegram 账号只能绑一个站点账号，反之亦然；绑定满 7 天才能解绑。
- 邀请只认**第一次**进群的 Telegram 账号：曾经在群里出现过（发过言、退过群）的账号再通过邀请链接进群不算；邀请自己绑定的 Telegram 账号不算；同一个站点账号作为被邀请人只算一次。
- 邀请 30 天内没有满足条件的作废。
- 每一笔奖励都是余额流水里的「活动奖励」，后台「站点设置 → Telegram」能看到已绑定人数、今日签到数、今日和累计发放金额。
- 余额不能提现，奖励只能在本站消费。

建议先用较小的金额和每日总预算试运行，观察一段时间再调整。

## 用 Telegram 接收通知

绑定了 Telegram 的客户可以在「账户资料 → 通知方式」里选择通知发到哪里：邮件、Telegram，或两者都要，至少选一种。

- 适用于所有发给客户的通知：到期提醒、流量告警、工单回复、交易市场成交和下架、托管母机清退和退款，以及发给机主的母机离线、到期和工单通知。
- Telegram 通知由站点机器人私聊发送，内容和邮件相同，语言跟随客户在站点选择的语言。
- 邮箱验证和找回密码的邮件始终发到邮箱，不受这个选择影响。
- 只选了 Telegram 的客户，在机器人停用期间通知改发邮件；解绑 Telegram 后通知方式自动恢复为邮件。
- 客户在 Telegram 里屏蔽了机器人时，这条通知发送失败、不再重试；之后的通知仍会尝试发送。
- 没有配置发信邮箱（SMTP）也可以只用 Telegram 发通知；两者都没有配置时不产生通知。

后台「站点设置 → 邮件通知」里的各项开关（到期提醒、流量告警、交易通知等）对两种渠道同时生效。
