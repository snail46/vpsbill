# 账户余额、托管中心与交易市场

## 账户余额

- 每个客户账户有一个余额，币种与账户计费币种相同。余额只能用于本平台消费（新购、续费），**不支持提现**。
- 余额来源：充值、托管收益、托管清退补偿、管理员调整。支出：余额支付、托管清退赔付。
- 所有变动写入只追加的余额流水（`wallet_entries`，数据库触发器禁止修改和删除），每条记录变动后余额。
- **充值**：客户在「账户余额」输入金额（¥1–¥100000），系统生成类型为 `topup` 的账单。配置了在线支付时直接跳转收银台；否则由管理员在「账单与交易」点「确认到账（充值）」，到账后余额自动增加。
- **余额支付**：「订单与账单」和托管市场购买弹窗里，待付的新购/续费账单可以直接用余额支付，余额不足时按钮不可用。余额支付与其他支付走同一套入账流程（开通、续费、托管资金）。
- **管理员调整**：「客户管理 → 余额明细」可以增加或扣减余额，必须填写原因，写入审计日志。扣减不能让余额变为负数。

## 托管中心

用户可以把自己的服务器通过 Hatch Agent（LXC / Podman）接入平台，自己定套餐和价格，出售给其他用户。平台作为中间方托管资金并收取手续费（默认 20%，「站点设置 → 托管中心」可改）。

### 发布流程（机主）

1. 「托管中心 → 我的母机 → 发布母机」，阅读并逐条勾选 5 条托管准则。
2. 在自己的服务器上以 root 运行页面给出的 Agent 安装命令，脚本最后打印 64 位令牌。
3. 填写母机名称、地域、**真实的地理位置、线路描述、租约到期日、整机月流量限额**和令牌。平台确认 Agent 已连上后上架。
4. 为母机创建套餐：配置、带宽、NAT 端口数、可选镜像（从母机读取）、各周期价格。单个实例配置不能超过母机真实资源；可售总量 = 真实资源 × 超售倍数（见下文「超售与负载」）。
5. 套餐还可以设置：
   - **套餐描述**（最多 1000 字，展示在托管市场）；
   - **限购**：每个买家最多持有几台（1–100）。按买家在该套餐上未终止的实例加上还能支付的未付订单计算，退款或终止后名额释放；
   - **允许早期全额退款**：见下文「退款」。

站点没有 HTTPS 时，Agent 只允许经回环地址用 HTTP 连接，所以只有与计费站同机的服务器能接入；对外开放托管需要先配置域名和 HTTPS。

### 购买（买家）

「托管中心 → 托管市场」列出在线、在售的托管母机和套餐，显示机主、位置、线路、到期日、流量限额和剩余资源。下单时会提示实例由第三方提供、机主拥有 root 权限。不能购买自己的母机；母机租约早于本计费周期结束时拒绝下单。开通、SSH、控制台、端口映射、重装、续费、欠费暂停等与平台自营实例完全相同。

### 退款

买家可以在「我的 VPS」对托管实例点「申请退款」，先看到按当前规则算出的金额，确认后立即执行：

- **早期全额退款**：套餐开启了该选项，且在购买（首次付款）后 1 小时内、实例流量不超过 1 GB 时，退还全部托管中的金额（含已预付的续费）。流量在申请时从母机实时读取，读不到时按比例退款。
- **按剩余天数比例退款**：其他情况。每个计费周期按整天计，当天算作已使用，买家拿回剩余整天对应的金额；未开始的预付续费全额退回。
- 退款进入买家余额（不可提现）。已使用部分按原比例结算：机主拿到对应的收益份额，平台保留对应的手续费。
- 实例标记为已终止并从母机删除，未付的续费账单作废，买家和机主都会收到邮件。
- 确认时会核对金额；如果在查看和确认之间规则结果变了（例如刚过 1 小时），会提示重新确认。

### 优惠码

优惠码分两条线，互不相通：

| | 谁创建 | 适用范围 |
|---|---|---|
| 平台优惠码 | 管理员，「商品套餐」页底部 | 平台自营套餐 |
| 机主优惠码 | 机主，「托管中心 → 优惠码」 | 该机主自己母机上的套餐 |

每个优惠码可以设置：

- 优惠方式：按比例减免（1%–99%）或每台每期固定减免金额。优惠只作用于套餐价格，不作用于开通费；无论如何买家至少支付 ¥0.01。
- 适用套餐：不选表示该所有者的全部套餐。
- 最大使用次数：0 表示不限；每台被优惠的实例算一次。已支付订单和仍可支付（未过期）的未付订单都计入。
- 到期日期（可选）：按 UTC+8，当天 24:00 后失效。
- 续费同价：开启后，用这个码购买的实例每次续费都按同样的折扣从当时的价格中扣减；关闭则只优惠首期。实例买下后，修改或停用优惠码不影响它的续费折扣。

机主不能使用自己的优惠码。托管套餐用了优惠码时，托管资金、手续费和清退、退款都按实付金额计算。

### 资金结算

- 付款（新购或续费）成功时生成一笔托管资金：`毛额 = 实付金额`，`手续费 = 毛额 × 手续费比例`，`机主份额 = 毛额 − 手续费`。
- 后台任务每 10 分钟运行一次，按**已过去的整天数**把机主份额按比例释放到机主余额（收益记录写明第几天）。实例还没开通成功时不释放。
- 未释放的部分就是**实例剩余价值（托管余额）**。

### 清退

| 触发 | 倍数 | 说明 |
|---|---|---|
| 母机离线满 N 小时（默认 24，站点设置可改） | 2 倍 | 系统自动执行；离线满 1 小时先给机主发提醒邮件 |
| 机主「下架母机」 | 2 倍 | 页面先显示将赔付的金额，确认后执行 |
| 管理员「清退」 | 1 或 2 倍 | 1 倍用于机主提前说明的特殊原因 |

清退时，对母机上每个未终止的实例：

- 买家获得 `倍数 × 剩余价值` 的余额补偿；其中一份来自未释放的托管资金，2 倍时另一份从机主余额扣除（可以扣成负数）。
- 实例标记为已终止并注明原因，未付续费账单作废，未执行的任务取消，占用的资源释放。
- 母机退出市场，套餐停售；母机在线时同时删除上面的实例。
- 机主和每个买家都会收到邮件，写明金额。

机主余额为负时不能发布新母机，之后的收益会先抵扣。管理员可以给离线母机设置「暂缓清退」（最长 90 天），期间不会自动清退。

### 托管工单

买家对托管实例提交的工单自动归属机主。机主在「托管中心 → 托管工单」回复（标记为「机主」），买家收到邮件。管理员在「客户工单 → 托管工单」可以查看并介入回复，但不是第一处理人；机主看不到管理员的内部备忘。

### 聊天室

每台托管母机一个聊天室，成员是机主和在这台母机上有有效实例的买家（实例终止后自动退出）。消息保存在数据库，通过 WebSocket 实时推送（多个 API 实例之间用 PostgreSQL `LISTEN/NOTIFY` 同步），断线重连后自动补齐。管理员在「托管管理 → 聊天室」能看到所有聊天室并以「平台」身份发言。母机清退后聊天室只读。

## 管理后台

- 「托管管理」：所有托管母机的机主、在线状态和离线时长、实例数、托管中资金、手续费收入、机主余额；操作有暂停/恢复销售、暂缓清退、清退（选倍数并填写原因，原因会发给机主和买家）。点母机名称展开实例明细。
- 「客户管理」：显示每个客户余额，「余额明细」查看流水和调整余额。
- 「站点设置 → 托管中心」：开关托管中心、手续费比例（0–90%）、离线清退时限（1–720 小时）。

## 交易市场

用户之间可以转让正在运行的实例（平台自营和托管实例都可以），用账户余额成交。

- **挂售**：「我的 VPS」里正常运行、并且当前主人已持有满 31 天的实例，点「挂售到交易市场」，填写价格（¥1–¥100000）和可选说明。持有时间从购买或上一次交易成交时算起。距到期不足 3 天、节点离线或因流量用尽停机的实例不能挂售。
- **挂售期间冻结**：挂售时平台读取实例本月的流量（上行、下行分开记录）作为展示给买家的数据，然后把实例关机。挂售期间卖家不能开机、登录、重装、重置密码或修改端口映射，只能查看监控，所以买家看到的流量和数据就是上架时的状态。卖家可以在「交易市场 → 我的挂售」随时下架，下架后自行开机。
- **到期时间照常计算**：挂售不会暂停或延长剩余天数。拿实例挂高价「占着」只会让它在停机状态下白白过期，所以没有必要这样做；距到期不足 3 天时挂售自动下架，卖家可以续费后重新挂售。
- **买家能看到的**：套餐配置、地域、是否托管母机、到期时间、续费价格（含续费同价折扣和托管锁价）、上架时的本月流量（上下行明细）、开通时间、卖家说明、卖家名（只显示首字）。看不到 IP、实例名和密码。
- **购买**：页面顶部和购买弹窗都提示「交易有风险，购买不退款。平台不保证机器的长期稳定性，请谨慎购买。」，买家须勾选确认。只能用余额支付；余额不足先充值。卖家不能买自己的挂售，机主不能买自己母机上的实例，实例所在母机离线时不能购买。
- **成交**：买家余额扣款；平台按成交价收取手续费（默认 20%，「站点设置 → 托管中心」可改），由卖家承担，其余进入卖家余额（不可提现）。实例、剩余时长、未付续费账单和托管资金一起转给买家并自动开机；平台保存的 root 密码被清除，买家需要在「我的 VPS」重置密码，建议重装系统。卖家已打开的 WebSSH 和聊天室连接会在 30 秒内断开。双方都会收到邮件。
- 实例在挂售期间停机、欠费、终止或被退款时，买家看不到它；有人下单时会自动下架。
- 管理员在后台「交易市场」查看所有挂售和成交记录，可以下架违规挂售并写明原因。

## 流量

全平台的流量都按**上行加下行双向合计**计算：套餐月流量、整机流量限额、流量提醒邮件和交易市场展示的流量都是两个方向之和。客户在「我的 VPS」能看到本月下行、上行和合计，交易市场展示上架时的明细。

实例本月流量超过套餐月流量时，平台会把它关机并锁定到下个月（按 UTC+8 自然月，与 Hatch Agent 的计数周期一致），期间客户不能开机；到了下个月平台自动解锁并开机。LXDAPI、CLICD 自己的流量限制仍然生效，平台这层按双向合计兜底。

## 托管的其他保护

- **续费锁价**：托管实例续费时，价格不超过买入时的单价。机主之后涨价只影响新订单，降价则老用户同样享受。
- **资源核定**：母机资源由机主的 Agent 检测上报，平台无法直接核实。买家可以在托管市场举报「实际资源与宣传不符」或「性能严重不足」，并附上实例里 `free -m; df -h /` 的结果（Podman 实例的 CPU 按配额限制，`nproc` 显示的是母机核数）。管理员在「托管管理 → 用户举报」处理举报，可以暂停该母机销售，或在「托管母机 → 核定资源」设置真实资源上限，之后 Agent 上报更高的数值也按上限计算。

## 超售与负载

NAT 小鸡允许适量超售，但必须公开、有上限：

- **可售资源 = Agent 检测的真实资源 × 超售倍数**。Agent 配置只能调低检测值，不能调高。
- 机主在「我的母机 → 超售设置」按 CPU、内存、硬盘、月流量分别设置倍数；管理员可以为任何母机设置。倍数不能超过「站点设置 → 超售倍数上限」（默认 CPU 4 倍、内存 1.5 倍、硬盘 2 倍、月流量 3 倍）。托管市场公开显示每台母机的倍数。
- 月流量超售相对「母机月流量额度」计算：已售实例的套餐流量合计不超过额度 × 倍数；母机没填额度时不限制。
- 同一台机器上的多个节点（例如 Incus 和 LXD 各跑一个 Agent）按本机标识识别，预留资源合并计算，不会重复出售。
- 每台实例都有硬盘限额，超售的只是还没用满的空间；某个实例写满自己的限额也影响不到别人。
- **负载过高自动暂停销售**（已售实例不受影响，恢复后自动继续）：可用内存持续 30 分钟低于 5%；任一实例存储用量超过 95% 持续 10 分钟；15 分钟平均负载持续 24 小时超过核数的 3 倍；或 Agent 报告无法限制实例硬盘。暂停时会给机主（平台自营母机给管理员）发邮件。长期不恢复的，管理员可以按清退规则处理。
- **聊天室管理**：每人在一个聊天室里 30 秒内最多发 5 条、10 分钟内最多 60 条。买家可以举报消息，管理员可以按小时禁言、解除禁言。
- **开通失败退款**：实例开通失败（多次重试后放弃）时，无论托管实例还是平台自营实例，客户都可以在「我的 VPS」申请全额退款到余额。

## 账户安全

- 新注册的客户需要验证邮箱：注册后收到验证邮件，验证前不能下单、充值、发布母机、参与交易、发聊天消息或举报，平台也不会给未验证的地址发通知邮件。站点没有配置发信邮箱时跳过验证。
- 二步验证码在 30 秒有效期内只能使用一次。
- 同一个 IP 每 15 分钟最多注册 10 个账户。
