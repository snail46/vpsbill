# VPS 续费与欠费生命周期

后台生命周期工作器默认每分钟执行一次，所有阶段均通过数据库唯一键、行锁和任务去重键保证可重复执行。

1. 到期前 `RENEWAL_LEAD_TIME`（默认 7 天）按套餐当前有效周期价格生成续费账单。
2. 到期未支付后服务进入 `overdue`，通知事件包含宽限截止时间。
3. 超过 `OVERDUE_GRACE_PERIOD`（默认 3 天）后进入 `suspended`，并设置删除时间。节点支持暂停（LXDAPI、Hatch）时冻结实例，内存状态保留、付款后秒级恢复；不支持时（CLICD）关机。
4. 暂停后 `TERMINATION_RETENTION`（默认 7 天）仍未付款，续费账单变为无法收回并排队删除实例。
5. 宽限期或暂停期内付款会推进 `next_due_at`；已暂停实例自动排队恢复：被冻结的先解冻，已关机的再开机。
6. 删除成功后释放节点库存预留；删除任务连续失败会进入人工处理状态，不会伪造成功。

付款与异步停机存在竞态时，付款事务会取消尚未执行的欠费停机任务；若停机已经开始或完成，则追加去重的恢复启动任务，保证已付款服务最终回到运行状态。

客户自己关机不会暂停计费，到期时间照常计算（关机确认框里会说明）。

找不到当前币种与周期价格时，系统不会生成错误金额或直接停机，而是把服务置为 `review` 并发送 `service.renewal_price_missing` 通知。

CLICD 删除使用官方接口 `DELETE /api/v1/containers/{id-or-name}/delete`，节点 API Key 需要 `container:delete` 权限。关机和恢复需要 `container:power` 权限。
