# 多语言与多币种

## 语言

客户前台和管理后台都提供中文和 English。

- 访客第一次打开时按浏览器语言显示：中文浏览器显示中文，英文浏览器显示英文，其他语言显示「站点设置 → 语言与币种」里的默认语言。
- 页面右上角的地球按钮可以随时切换，选择保存在浏览器里；切换后页面会重新加载。
- 登录后的客户所用的语言会记到账号上，之后发给他的邮件（到期提醒、流量告警、工单回复、交易和清退通知、邮箱验证、找回密码）和 Telegram 机器人的回复都用这种语言。还没有选过语言的账号用站点默认语言。
- 发给管理员的邮件用站点默认语言。

不翻译的内容：管理员和用户自己录入的文字，例如套餐名称与描述、分类、地域、公告、联系方式、工单和聊天内容、优惠码说明、机主填写的线路描述。需要双语时请直接写成双语（例如「香港 Hong Kong」）。

### 文案是怎么组织的

界面用中文编写，英文是一份以中文原文为键的字典：

| 文件 | 内容 |
| --- | --- |
| `web/src/shared/i18n.ts` | `t()` 翻译界面文案，`tr()` 翻译服务端返回的文字 |
| `web/src/locale/en-ui.ts` | 界面文案的英文，`{0}`、`{1}` 是句子里的变量 |
| `web/src/locale/en-server.ts` | 服务端返回的中文（接口提示、余额流水说明、下架和清退原因等）的英文：整句对照，加上带变量的匹配规则 |
| `internal/notify/`、`internal/telegram/messages.go` | 邮件和机器人回复，中英文写在一起 |

新增或修改界面文案时：

1. 代码里写 `t('中文文案')`，带变量写 `t('已选 {0} 个套餐', count)`；
2. 在 `web/src/locale/en-ui.ts` 加上同一个键的英文；
3. `npm run build`（或 `npm run i18n`）会检查：每个 `t()` 的文案都要有英文，英文里的占位符不能超出中文原文。漏了会直接报错并列出缺的条目。

服务端新增返回给页面的中文提示时，在 `web/src/locale/en-server.ts` 的 `serverWords` 加整句对照；带变量的（例如 `fmt.Sprintf("库存最多 %d 台")`）在 `serverRules` 加一条正则，`$1` 原样放入匹配到的内容，`%1` 会把匹配到的内容再翻译一遍。没有对照的提示在英文界面下按中文原样显示。

## 币种

### 记账币种

账本只用一种币种，叫**记账币种**，可以是人民币（CNY）或美元（USD）。客户余额、套餐价格、订单、账单和流水都按它记账和扣款。新安装的站点是人民币。

在「站点设置 → 记账币种」可以切换（只有超级管理员能操作）。切换是一次整体换算：

- 按当时的站点汇率，把**所有**金额一次性换算成新币种：账户余额、套餐价格、未付和已付的账单、订单、流水、托管中的款项、交易市场挂售价、金额型优惠码、Telegram 奖励记录。换算在一个数据库事务里完成，中途失败则什么都不变。
- 换算四舍五入到分，原来不为零的金额至少保留 0.01。套餐价格换算后通常不是整数（例如 ¥19.80 按 6.71 换算成 $2.95），切换后请检查并调整套餐价格；交易市场挂售价不低于 1.00。
- 切换后新注册的账户、新建的套餐价格、充值和奖励都按新币种。
- 可以用同样的方式切换回来。来回切换会有分位的舍入误差（每个金额各自四舍五入），不会精确还原，所以不要频繁切换。
- 每次切换记入「切换记录」和审计日志（`ledger.currency_switched`）。建议切换前先在「数据备份」里做一次备份。

切换的限制：有在线支付正在进行时（收银台已创建、30 分钟内未过期）不能切换，因为那笔支付的金额是按旧币种约定的。请先停用支付网关，等未完成的支付过期后再切换。

流水和交易记录平时不可修改；记账币种切换是唯一的例外，它把历史记录一起换算，使账本始终只有一种币种。支付网关当时回调的原始内容（含实际支付的金额和币种）保存在支付事件里，不受换算影响。

### 在线支付

支付宝当面付和易支付只收人民币。记账币种是美元时：

- 创建收银台时，按当时的站点汇率把美元金额折算成人民币向网关收取；
- 网关回调时核对的是这笔人民币金额；到账仍按账单的美元金额记入（充值到账的余额是美元）。
- 充值页会在输入框旁标出「实付约 ¥x」。

通用 HMAC 收银台按账单币种和金额下单，由你的收银台自己处理币种。

### 显示币种

前台可以用人民币、美元或两种币种显示金额，在「站点设置 → 语言与币种」设置：

- **显示哪些币种**：只显示人民币、只显示美元，或两种都显示。两种都显示时访客可以在右上角切换；只显示一种时前台不出现币种切换。
- **默认币种**：访客第一次访问看到的币种。切换记账币种时，默认币种会一起改成新的记账币种，之后可以再调整。
- **汇率**：1 USD 兑多少 CNY，可以每 6 小时自动更新为市场汇率，也可以点「立即获取当前汇率」或手动填写。自动更新依次读取 `open.er-api.com` 和 `api.frankfurter.dev` 两个公开汇率接口，都失败时保留原来的汇率；服务器访问不了外网时请关闭自动更新，手动填写。

访客用记账币种以外的币种查看时，金额按汇率换算显示，实际扣款仍然是记账币种的金额：

- 涉及金额的页面顶部会提示换算汇率，待付金额旁会用括号标出实际扣款的金额。
- 充值按访客当前看到的币种填写，换算成记账币种生成充值账单。
- 交易市场挂售价、机主套餐定价、优惠码减免金额、后台的套餐价格和余额调整，填写的都是记账币种。
- Telegram 奖励金额在后台按默认币种填写，机器人和前台按默认币种展示；默认币种和记账币种不同时，发放时按当时的汇率换算后存入余额。
- 管理后台始终按记账币种显示；邮件里的金额是记账币种。

显示用的换算不改变任何已有账单或余额；只有切换记账币种才会改变账本里的金额。
